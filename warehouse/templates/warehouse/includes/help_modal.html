{% trans "How to use the catalogue" %}

{% trans "1. Search:" %}

  • {% blocktranslate trimmed %} Enter keywords you are interested in into the "Search term" field. The catalogue will search through dataset names, descriptions and keywords. {% endblocktranslate %}
  • {% blocktranslate trimmed %} Press the "Search" button (if available). {% endblocktranslate %}

{% trans "2. Filtering:" %}

  • {% trans "Filters are available in the left panel." %}
  • {% trans "You can filter by:" %}
    • {% trans "Keywords:" %} {% blocktranslate trimmed %} Check relevant keywords. You can use the search field within each filter section for faster searching. {% endblocktranslate %}
    • {% trans "Data source:" %} {% trans "Select which source the data comes from." %}
    • {% trans "Rights holder:" %} {% trans "Display datasets managed by a specific rights holder." %}
  • {% trans "After checking the filters, the corresponding datasets will be automatically displayed." %}
  • {% blocktranslate trimmed %} To clear all set filters, click the "Clear filters" button. {% endblocktranslate %}

{% trans "3. Browsing datasets:" %}

  • Každá datová sada je zobrazena jako karta. Na podřazených kartách se zobrazují příslušné datové třídy a datové tabulky .
  • Kliknutím na název karty rozbalíte/sbalíte detailní informace, včetně popisu, klíčových slov, zdroje dat a držitele práv.
  • Ikonky vpravo nahoře na kartě:
    • Indikuje, že informace o dané entitě jsou kompletní.
    • Indikuje, zda jsou data uložená v datovém skladu.
  • V pravém dolním rohu karty se nachází ikonka Zobrazit/skrýt tabulky. Kliknutím na ni zobrazíte seznam souvisejících databázových tabulek (pokud existují).
  • U každé zobrazené tabulky můžete kliknout na název pro zobrazení jejího popisu (pokud je k dispozici).
  • U tabulek je také k dispozici ikonka Zobrazit proměnné (lupa), která po kliknutí zobrazí modální okno s proměnnými dané tabulky a informací o tom, jaké jsou zde použity slovníky.
